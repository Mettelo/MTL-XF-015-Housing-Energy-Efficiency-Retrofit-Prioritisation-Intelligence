# Data Workspace

**Primary dataset:** National Energy Efficiency Data-Framework (NEED) Anonymised Data 2026 — 50,000-row sample  
**Publisher:** Department for Energy Security and Net Zero  
**Format:** CSV  
**Official source:** https://www.gov.uk/government/statistics/national-energy-efficiency-data-framework-need-anonymised-data-2026

Mettelo uses a frozen cohort version/reference so the project remains reproducible if the publisher later changes its website. Preserve raw files unchanged and record version/acquisition details in `SOURCE_REGISTER.md`.
