# MTL-XF-015 — Housing Energy Efficiency, Consumption & Retrofit Prioritisation Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential Regional Housing & Net Zero Investment Authority |
| Sector | Housing / Energy / Net Zero |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Director of Housing Investment |
| Engagement | Simulated confidential-client engagement |

The authority has a constrained retrofit budget and cannot fund every eligible property. Previous prioritisation has relied too heavily on headline efficiency ratings rather than combining property characteristics, consumption evidence and intervention history.

**Commissioned decision:** Which property segments should receive retrofit investment first to maximise defensible energy-efficiency benefit while keeping the prioritisation transparent and fair?

This is an end-to-end multidisciplinary engagement, not a dashboard-only exercise.
