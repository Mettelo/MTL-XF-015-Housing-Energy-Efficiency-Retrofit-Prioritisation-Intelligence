# MTL-XF-015 — Housing Energy Efficiency, Consumption & Retrofit Prioritisation Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Project ID | MTL-XF-015 |
| Client | Confidential Regional Housing & Net Zero Investment Authority |
| Sector | Housing / Energy / Net Zero |
| Duration | 8 weeks |
| Recommended Team Size | 6–8 |
| Primary Sponsor | Director of Housing Investment |

The authority has a constrained retrofit budget and cannot fund every eligible property. Previous prioritisation relies too heavily on headline efficiency ratings, with limited use of actual consumption, property characteristics or intervention history.

**Decision to support:** Which property segments should receive retrofit investment first to maximise defensible energy-efficiency benefit while keeping the prioritisation transparent, explainable and fair?

This is an end-to-end delivery engagement, not a dashboard-only exercise.
