# Agreed Acceptance Criteria

1. **AC1:** The curated table retains a documented one-row-per-property/sample-unit grain and all derived fields are reproducible.
2. **AC2:** At least five major analytical measures reconcile to direct calculations from the frozen NEED sample.
3. **AC3:** Any prioritisation score exposes every component and weight; no hidden composite logic is allowed.
4. **AC4:** At least three alternative weighting/scenario configurations are compared.
5. **AC5:** A proxy/fairness review documents variables excluded or restricted from prioritisation.
6. **AC6:** No recommendation is framed as proven causal retrofit impact without supporting evidence.
7. **AC7:** The dashboard separates measured data from scenario assumptions visually and textually.
8. **AC8:** A reviewer can rebuild the analytical dataset, segment analysis and prioritisation scenarios from the frozen sample without undocumented manual edits.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.

Map every criterion to requirement(s), artefact(s), test/reconciliation evidence, owner and status.
